# Share-Sheet-Lab

Find out what your apps are really sharing.

Share-Sheet-Lab is an iPhone shortcut that shows what another app actually sends through the Share Sheet. Inspect a note, photo, webpage, text selection, or file to see what Shortcuts receives before you build a workflow around it.

Created by 🐙SurfKraken.

## Installation

The signed iCloud download link will be added here before release.

## What it does

- Reports item counts, detected types, names, text lengths, and text previews.
- Opens readable reports with clear sections and larger text.
- Previews the original received input.
- Copies reports or saves them as text files.
- Compares a current input against an earlier saved report.
- Offers sample input, Photos, Files, clipboard, and typed text for testing.
- Checks automatically for updates when launched and offers Update Now or Not Now when a newer release is available.

## How to use it

- Open the source item in Notes, Photos, Safari, Files, or another app.
- Tap Share and choose Share-Sheet-Lab.
- Read the report, then dismiss it to use the menu.
- Open How to Use inside the shortcut for more guidance.

You can also launch the shortcut directly and choose New Test Input.

In Apple Notes, choose Send a Copy when sharing a note. Sharing a link can deliver a link instead of the note body.

## Saving and comparing

Choose Save Report and give the text file a useful name in Files. Inspect another input, choose Compare Saved Report, and select the earlier report.

Comparison covers received item count, order, detected types, listed names, and converted text. Images, PDFs, and other media use metadata only; matching reports do not prove identical media files. Older reports without a valid fingerprint can be opened for review but cannot produce a verified match.

Reports describe up to 20 items and show up to 500 characters of text per item. Text fingerprints cover the complete converted text. Original input remains available through Preview Input during the run.

## Privacy and requirements

Inspection uses first-party Apple actions, with no AI or helper apps. Shared input and report text are not uploaded to GitHub. Saved reports contain actual names and text excerpts, so review them before sharing.

Internet is required for the automatic update check. Native network failures or canceled system pickers can end a run. Files saved to iCloud Drive use normal system syncing.

## Updates

Release information lives in [latest.json](latest.json). The shortcut checks it automatically and opens the signed iCloud release only when you choose Update Now.
